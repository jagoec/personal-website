# About This Site

A quick tour of how this website works:

- **Written in Markdown** — pages are plain text files, rendered to static HTML by Eleventy. No frameworks, no database.
- **Versioned on GitHub** — every change goes through a feature branch and pull request before merging, so the site's whole history is recorded.
- **Hosted on Vercel** — merging to GitHub triggers an automatic build; Vercel serves the result from its CDN at christopherjagoe.com with automatic HTTPS, and every pull request gets a live preview URL.
- **Books via Google Sheets** — the reading list is pulled from a published spreadsheet at build time.
- **Search-ready** — sitemap.xml, robots.txt, and Open Graph tags (the preview cards you see when sharing a link), with a generated card image, registered with Google Search Console.
- **Privacy-friendly analytics** — Vercel Web Analytics counts visits without cookies.

Built and maintained with [opencode](https://opencode.ai), an AI coding agent — the repo's AGENTS.md file documents the project so the agent can pick up where we left off.
